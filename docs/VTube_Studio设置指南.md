# VTube Studio 设置指南

## 🎯 必须设置的项目

### 1. 热键设置（最关键！）
由于测试显示通过热键名称触发失败，您需要手动设置热键：

**操作步骤：**
1. 打开 VTube Studio
2. 点击左上角 **Menu** → **Settings**
3. 左侧选择 **Hotkeys**
4. 点击右下角 **Add Hotkey**
5. 为以下动作创建热键：

| 热键名称 | 建议动作类型 | 说明 |
|---------|-------------|------|
| Wave | Animation/手势 | 挥手动画 |
| Happy | Expression/表情 | 开心表情 |
| Clap | Animation/手势 | 鼓掌动画 |
| Nod | Animation/手势 | 点头动作 |
| Surprise | Expression/表情 | 惊讶表情 |
| Shy | Expression/表情 | 害羞表情 |
| Angry | Expression/表情 | 生气表情 |
| Heart | Animation/手势 | 比心手势 |
| Jump | Animation/手势 | 跳跃动作 |

### 2. 面部追踪参数确认

**关键理解：输入参数 vs 输出参数**

| 类型 | 名称 | 含义 | 控制方式 |
|-----|------|------|----------|
| **输入** | `FaceAngleX/Y/Z` | 面捕追踪数据（摄像头）| 自动追踪 |
| **输出** | `ParamAngleX/Y/Z` | 实际驱动模型的参数 | ⭐ Python代码控制 |

**重要：Python代码要控制的是输出参数 (`Param` 开头)，不是输入参数！**

**常见输出参数列表：**
- `ParamAngleX` - 头部左右转动 (-30到30度)
- `ParamAngleY` - 头部上下转动 (-30到30度)
- `ParamAngleZ` - 头部倾斜 (-30到30度)
- `ParamMouthOpenY` - 嘴巴张开 (0.0到1.0)
- `ParamEyeLOpen` - 左眼睁闭 (0.0到1.0)
- `ParamEyeROpen` - 右眼睁闭 (0.0到1.0)
- `ParamEyeBallX/Y` - 眼球转动 (-1.0到1.0)
- `ParamBodyAngleX` - 身体倾斜 (-10到10度)
- `ParamBreath` - 呼吸动画 (0.0到1.0)

### 3. 关闭输入绑定（重要！）
为了让Python代码完全控制角色，需要在VTube Studio中关闭对应参数的输入绑定：

1. 在模型参数设置中找到要控制的参数
2. 点击参数旁边的 **"输入"** 开关，将其关闭
3. 或者点击输入行的 **🗑️ 删除图标** 移除绑定

这样面捕系统就不会覆盖您的API指令了。

### 4. API设置确认
1. 在 Settings 中找到 **API** 选项
2. 确保 **Enable Access** 已勾选 ✓
3. 确认端口号为 **8001**（默认）
4. 如果有防火墙提示，允许访问

### 4. 模型要求
- 加载支持动画的Live2D模型
- 确保模型包含上述表情和动作资源
- 可以在模型的Animation和Expression标签页查看可用动作

## 🔄 设置完成后测试步骤

## 🎮 控制功能说明

### 动作控制
- 通过热键触发预设的动画和表情
- 支持挥手、鼓掌、点头等身体动作
- 支持开心、生气、害羞等面部表情

### 面部追踪控制
- 直接控制面部参数数值
- 可以实现更细腻的表情控制
- 支持实时调节面部特征

### 综合控制
- 动作和表情的组合表演
- 同步控制多个参数
- 创建复杂的互动场景

## 📋 常见问题排查

**Q: 连接成功但动作无响应？**
A: 检查热键是否正确设置，名称必须完全匹配

**Q: 面部参数无法控制？**
A: 确认模型支持该参数，或在VTube Studio中查看可用参数列表

**Q: 认证总是失败？**
A: 确认API已启用，防火墙未阻止端口8001

**Q: 某些动作无法执行？**
A: 检查模型是否支持该动作，或在VTube Studio中重新分配热键

设置完成后，角色就能通过我们的Python脚本正常动起来了！
